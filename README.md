# Home Network Security Lab — Networking → Security+ Foundations

Hands-on networking and security labs built on a home lab (TP-Link TL-SG108E managed switch, TP-Link router, AR9271 wireless adapter) as preparation for CompTIA Security+ and entry-level IT/security roles.

**Every wireless and exploitation technique in this repo was performed exclusively against hardware I own.** No lab here targets a third-party network or device.

## Background

This lab follows a structured 8-module self-study path through networking fundamentals (OSI/TCP-IP, addressing, protocols, hardware, wireless, WAN, troubleshooting) before moving into CompTIA Security+ specific material. Each lab folder contains a README with objective, setup, commands run, findings, and screenshots/captures.
